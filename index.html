Публикация на GitHub Pages

Хаб с твоими ссылками загрузится в публичный репозиторий GitHub и станет сайтом вида логин.github.io/репозиторий. Ссылку можно отправлять друзьям, обновление в один клик.

Как получить токен
  1. Нажми «создать токен»: откроется GitHub с уже отмеченным доступом repo.
  2. Выбери срок действия и нажми Generate token.
  3. Скопируй токен и вставь сюда. Он хранится только в этом браузере и не попадает в опубликованный файл.
Репозиторий будет публичным: так GitHub Pages работает на бесплатном аккаунте. Не добавляй в хаб ничего секретного.
